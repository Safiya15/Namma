Studio Namma Clone

A front-end clone of https://studionamma.com/— a professional branding and design agency website.

Live Demo


Coming soon



Features


Dark Mode Toggle — switches background and text colors across the page
Animated Contact Overlay — full-page contact form that slides in from the top on clicking "LET'S TALK!"
GIF Animation on Contact — GIF slides in with a smooth transition when contact overlay opens
Interactive Menu Overlay — full-page navigation menu with 3D rotation animation on open
Hover Effects on Menu — GIF appears and text shifts right on hovering each menu item
Interest Button Selection — clicking DESIGN / WEBFLOW DEVELOPMENT / FULL PACKAGE highlights the selected option
Responsive Nav Bar — fixed navigation with hover text change effects


Built With


HTML5
CSS3 (Flexbox, CSS Animations, Transform, Transitions)
Vanilla JavaScript (DOM Manipulation, Event Listeners, classList API)

Concepts Used


position: fixed for overlays
transform: translateX() for slide animations
transform: rotateX() for 3D menu rotation
z-index layering for overlay stacking
classList.add/remove/contains for toggling states
setTimeout for delayed animations
querySelectorAll + forEach for bulk event listeners
